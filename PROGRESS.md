## Этап 3. Медиа-подсистема — ✅

Сделано:

- **`StorageProvider`** (§3.1) с методами `presignPut / put / get / getBuffer / exists /
  delete / publicUrl / list`.
  - `local.provider.ts` — папка на диске. Тоже выдаёт presigned-ссылку (HMAC + TTL 15 мин),
    указывающую на сам backend: клиентский путь загрузки не отличается от R2.
  - `r2.provider.ts` — 🟡 написан на `@aws-sdk/client-s3`, не запускался. Тот же код
    подходит для MinIO и Backblaze B2.
- **Загрузка напрямую в хранилище, минуя backend** (§3.2): presign → `PUT` из браузера
  через `XMLHttpRequest` с прогрессом → `complete` → задача в очередь.
- **Дедупликация по sha256**: браузер считает хеш до загрузки; если такой файл уже есть,
  сервер возвращает существующий `Media` и загрузка не происходит вовсе.
- **Обработка картинок** (sharp): автоповорот по EXIF, метаданные вырезаются,
  ширины 320/640/960/1280/1920 (без апскейла) × AVIF + WebP, blurhash.
  Ключи вида `img/<sha8>/<width>.avif` — content-hash, поэтому кэш `immutable`.
- **Видео** (§3.4): ffprobe → длительность и размеры, постер на 10% длительности,
  `variants` сразу массивом рендишнов (лестница качеств этапа 7 ляжет без миграции).
  Без ffmpeg видео сохраняется и играет, а причина отсутствия постера видна в админке.
- **Очередь pg-boss** поверх того же Postgres. Если очередь не поднялась, задачи
  выполняются прямо в процессе — обработка не встаёт молча.
- **Медиа-библиотека в админке**: сетка с превью, вкладки по типу, поиск,
  drag-and-drop и выбор файлов, прогресс по стадиям (хеш → загрузка → обработка),
  карточка файла (варианты, alt, «где используется»), удаление с проверкой ссылок.

Проверено запуском (полный цикл через curl):

| Проверка | Результат |
|---|---|
| Загрузка PNG 1600×900 | READY за ~2 с, 8 вариантов (AVIF+WebP × 4 ширины), blurhash есть |
| 1920px-вариант у картинки шириной 1600 | не создан — апскейла нет |
| `curl -I` на вариант | `cache-control: public, max-age=31536000, immutable`, `content-type: image/avif` |
| Повторный presign того же файла | `deduplicated: true`, загрузка не потребовалась |
| Подделанная подпись в ссылке загрузки | 403 |
| Видео без ffmpeg | READY, играет (`206 Partial Content` на Range), причина отсутствия постера видна в UI |
| Удаление используемого файла | 409 со списком гайдов |

**Замечание по sha256 в браузере.** План говорит «стримом», реализовано через
`crypto.subtle.digest` по файлу целиком: у SubtleCrypto нет потокового API, а своя
реализация SHA-256 в бандле ради редких больших видео не окупается (скриншоты —
единицы мегабайт). Для файла в сотни мегабайт шаг заметен по времени, поэтому в UI
показывается стадия «считаю хеш».
